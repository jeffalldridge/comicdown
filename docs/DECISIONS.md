# DECISIONS — comicdown (CLI)

Lightweight decision log: every significant call and **why**. Newest first;
supersede, never delete. GUI-side decisions live in the ComicDown-GUI repo's
docs/DECISIONS.md.

- **Download cloud placeholders with a coordinated read (`osascript`
  JXA `NSFileCoordinator`) before reading** — the Quick Action runs as a
  service with on-demand download of "dataless" files disabled, so a
  plain read of a not-downloaded iCloud file fails with EDEADLK and poppler
  reports "not a PDF". The coordinated read makes the file provider fetch
  the file and blocks until it is local; it uses only macOS built-ins and
  also works for other File Providers. `brctl download` was rejected: it
  is gone on current macOS. Detection is the SF_DATALESS flag from
  `stat -f %Xf`, so local files never invoke osascript. (2026-10-30)
- **Smart-DPI fallback (72–600 clamp from x-ppi/y-ppi) instead of blind
  300** — render at the page's inherent pixel density: low-res art isn't
  upscaled past its own resolution, high-res scans aren't degraded; poppler
  already reports effective ppi so it's nearly free. (2026-08-05)
- **`pdfimages -all` byte-passthrough as the core; render only what fails
  verification** — lossless extraction is the entire reason this tool
  exists; existing converters re-render everything and bloat 50–100%.
  Per-page fallback means one messy page never forces re-encoding a book.
  (2026-08-05)
- **CMYK detected by component count (≥4), not colorspace name** — ICC-
  wrapped CMYK reports `icc` in poppler's color column; name-matching
  misses it and ships broken pages as "lossless". Component count catches
  both. (2026-08-05)
- **Every side-effecting command explicitly guarded; no `[ cond ] && cmd`**
  — `convert_pdf` runs inside a command substitution, which suppresses
  `set -e` for its entire body (bash gotcha, empirically demonstrated: a
  failed write printed a success summary). Guards are correctness, not
  style. (2026-08-05)
- **Bash 3.2 target** — macOS system bash; zero install friction for a
  brew-poppler-only tool. Costs: no associative arrays, empty-array/set -u
  trap. (2026-08-05)
- **Store-only zip for pages** — JPEGs don't deflate; STORE is faster and
  keeps extraction cheap. (2026-08-05)
- **Quick Action probes installed bin dirs before the repo checkout, and
  exports PATH first** — launchd services get a minimal PATH (poppler
  invisible) and macOS privacy protection blocks exec from
  Documents/Desktop/Downloads; both were real failures on first manual
  test. Install step (`cp` to /opt/homebrew/bin) exists because of TCC,
  not convenience. (2026-08-06)
- **Sidecar `.cbz.log` only when fallback occurred** — a clean conversion
  needs no explanation; a log's existence is itself the signal something
  was rendered. (2026-08-05)
- **Summary strings are a contract** ("N/M pages lossless; rendered: …") —
  parsed by tests and by the GUI's parity harness; changes are breaking
  changes. (2026-08-06)
- **MIT + macOS-runner CI + PDF-attaching issue templates** — bug reports
  with a problem PDF are the most valuable contribution; the macOS runner
  is load-bearing (sips, system bash). (2026-08-05)
- **Fixtures generated by committed stdlib-only scripts** — reproducible,
  CI-safe, no real books ever committed (scrub rule). (2026-08-05)
