# AGENTS.md — comicdown (CLI)

Guidance for AI agents and contributors. This is the poppler-based CLI;
the native macOS app lives in the sibling `ComicDown-GUI` repo and mirrors
this tool's contract.

## Build & test

```sh
brew install poppler shellcheck
tests/run.sh                      # full suite (53 tests)
shellcheck bin/pdf2cbz tests/run.sh tests/*.test.sh
```

## Hard rules

1. **Lossless contract:** embedded images pass through byte-for-byte;
   anything uncertain falls back to rendering with an honest per-page
   reason. Summaries must never overstate losslessness.
2. **Bash 3.2 (macOS system bash).** No associative arrays, no `${var,,}`;
   never expand a possibly-empty array under `set -u`.
3. **errexit trap:** `convert_pdf` runs inside a command substitution, which
   SUPPRESSES `set -e` for its whole body — every side-effecting command
   carries an explicit `|| return 1`-style guard. Never write
   `[ cond ] && cmd` for optional steps (a false condition kills the run);
   always `if/then`.
4. **Runtime deps are brew poppler + macOS built-ins only.** Nothing else
   without an issue discussion.
5. **Scrub rule:** no copyrighted titles or personal-library filenames in
   tracked files or commit messages. `tests/samples/` is gitignored local
   corpus; `tests/samples/expectations.tsv` (untracked) is the shared
   parity contract also consumed by the GUI repo's `make qa`.
6. Fixtures are synthetic, generated by `tests/make-fixtures.py`
   (stdlib + sips) and committed; regenerate only when adding one, and
   diff against committed fixtures before committing regenerated bytes.
7. Tests never weaken to make code pass; every behavior change needs one.

## Architecture (single script, `bin/pdf2cbz`)

`classify_pages` (awk over `pdfimages -list`; emits
`<page> lossless|fallback <reason> <dpi|->` — reasons: mask, multi-image,
enc:<x>, cmyk, no-image; CMYK detected by component count ≥4, catching
ICC-wrapped CMYK) → `pdfimages -p -all` extraction (filenames parsed
padding-agnostically) → per-page verify/stage → `pdftoppm` fallback render
at the page's inherent DPI (72–600 clamp) → store-only zip → summary +
`.cbz.log` sidecar only when fallback occurred.

Before reading, `convert_pdf` calls `ensure_local`: a cloud placeholder
(iCloud "not downloaded", SF_DATALESS flag) is downloaded with a
Foundation coordinated read via `osascript`, because services run with
on-demand download disabled (plain reads fail with EDEADLK).

The Quick Action (`quick-action/`) must keep its `export PATH` line
(launchd services get a minimal PATH) and probe installed bin dirs BEFORE
the repo checkout (macOS privacy protection blocks service exec from
Documents/Desktop/Downloads).
